# Personal Finance Tracker

## Мета проєкту

Personal Finance Tracker допомагає вести облік доходів і витрат у гривнях, бачити поточний баланс і перевіряти, скільки грошей витрачено за місяць. Це консольна програма на C11 з окремими профілями та локальним зашифрованим сховищем.

## Встановлення та запуск

У Linux використовуйте термінал Ubuntu. У Windows відкрийте папку проєкту у VS Code з підключенням **WSL: Ubuntu** і відкрийте термінал через **Terminal → New Terminal**.

Встановіть залежності в Ubuntu.

```bash
sudo apt update
sudo apt install git build-essential libssl-dev libcurl4-openssl-dev libjson-c-dev
```

Якщо ще не маєте копії проєкту, завантажте її з GitHub і перейдіть до папки репозиторію.

```bash
git clone --branch feature/statistics-budget https://github.com/MaksymPrannychuk/Personal-Finance-Tracker_Project1_.git
cd Personal-Finance-Tracker_Project1_
```

Зберіть програму з кореня репозиторію. Користувацький режим відкривається після запуску без аргументів.

```bash
make
./build/finance_tracker
```

## Приклади використання

### Швидка перевірка в демо

```bash
./build/finance_tracker --demo
```

У демо є шість вигаданих транзакцій. Натисніть `2`, щоб переглянути їх, `14` для курсів валют або `0` для виходу. Зміни в демо діють до виходу. Збереження й резервні копії в цьому режимі вимкнені.

### Облік витрат у власному профілі

1. Запустіть `./build/finance_tracker` і в початковому меню виберіть `1` (**Create profile**). Введіть назву, наприклад `student`, і двічі введіть пароль від 8 символів. У назві дозволені малі латинські літери, цифри, дефіс і підкреслення. У терміналі символи пароля приховано.
2. У головному меню виберіть `1` (**Add transaction**). Для прикладу додайте дохід, ввівши по черзі `1`, `2000`, `2026-11-01`, `Salary`, `Test income`. Так само додайте витрату, ввівши `2`, `600`, `2026-11-02`, `Food`, `Groceries`. Після цього баланс становитиме **1 400,00 грн**.
3. Виберіть `6` (**Monthly report**) і введіть рік `2026` та місяць `11`. Щоб перевірити ліміт, виберіть `7` (**Monthly budget check**) і введіть `2026`, `11`, `Food`, `750`. Програма покаже, що витрачено **80%** і залишилося **150,00 грн**.
4. Виберіть `9` (**Save encrypted data**), а потім `0` для виходу. При наступному запуску виберіть `2` (**Open profile**) у початковому меню і введіть назву профілю та пароль.

## Що варто знати

- Транзакції можна редагувати, видаляти, сортувати за датою чи сумою і фільтрувати за точною назвою категорії, діапазоном дат і типом. Дата має формат `YYYY-MM-DD`. Один гаманець вміщує до 1 000 транзакцій.
- Бюджетний ліміт вводиться для однієї категорії й місяця під час кожної перевірки.
- Гаманець профілю зберігається в `profiles/p-<назва>/wallet.enc`. Пункт `10` створює зашифровану копію поруч із ним. Для відновлення через пункт `11` потрібен пароль, який діяв під час створення копії. Поточний пароль гаманця після відновлення зберігається. Пункт `12` змінює пароль, а `13` перевіряє цілісність збереженого гаманця.
- Пункт `14` завантажує публічні курси USD, EUR і PLN від monobank. Для нього потрібен інтернет.

## Перевірка

```bash
make test
```

Команда запускає 35 автоматичних перевірок. Вони охоплюють транзакції, пошук, звіти й бюджетні пороги, шифрування, резервні копії, профілі та обробку відповідей API курсів на тестових даних.

## Структура

- `app/` — головне меню, профілі, підключення сховища й курсів.
- `Onishchenko/` — керування транзакціями.
- `Pistryak/` — пошук, статистика й бюджети.
- `Prannychuk/` — файли сховища, шифрування й резервні копії.

Для шифрування файлів програма використовує AES-256-GCM через OpenSSL. Блокування файла через POSIX дозволяє відкрити один гаманець в одному сеансі. libcurl отримує курси через HTTPS, а JSON-C розбирає відповідь банку.
